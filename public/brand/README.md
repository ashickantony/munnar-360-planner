# Brand assets

Keep identity assets here; destination and package photography stays in
`public/images/`.

## Current contents

- `logo-full.png` — cleaned, transparent high-resolution lockup derived from the supplied JPEG.
- `icon.png` — transparent 512px standalone brand mark, also used as the app icon.
- `fonts/` — reserved for the approved brand typefaces.

## Files to provide for the final identity

Please add the best available originals using these names:

- `logo-full.svg` — complete logo lockup, including icon and typography.
- `logo-wordmark.svg` — typography/wordmark by itself, if available.
- `icon.svg` — standalone icon, preferably square and with a transparent background.
- `fonts/` — licensed `.woff2` font files, with the family name, weights, and
  styles provided. If fonts are not web-licensed, send the font names instead.

Vector SVGs are preferred. If only raster exports exist, provide transparent
PNG files at least 2× their intended display size. Keep source/print PDFs outside
this folder; add only the web-ready exports here.

The current header and footer already use `logo-full.png`; the favicon and web
manifest use `icon.png`. Replace those files in place if you later provide
original vector exports or a higher-quality standalone brand icon.
